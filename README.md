
# SYNTRIX COMPILER

Syntrix is a mini programming language compiler developed as an academic project.

## Project Overview

The project aims to design and implement a simple programming language using compiler construction tools.

## Technologies Used

- C
- Flex (Lexical Analyzer)
- Bison (Syntax Analyzer)
- GCC (Compiler)
- VS Code
- MSYS2 UCRT64

## Project Structure

- lexer.l - Lexical analysis
- parser.y - Syntax analysis
- main.c - Main program
- Makefile - Build automation
- README.md - Project documentation

## Current Features

- Keyword recognition
- Identifier recognition
- Integer and floating-point numbers
- Operator recognition
- String literals
- Basic syntax validation
- Arithmetic expressions
- Conditional statements
- Loop statements

## Project Status

Initial development in progress.
