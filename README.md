
# SYNTRIX COMPILER

Syntrix is a mini programming language compiler developed as an academic project using C, Flex, and Bison.

## Project Overview

The project aims to design and implement a simple programming language and its compiler components, including lexical analysis and syntax analysis.

## Technologies Used

- C
- Flex (Lexical Analyzer)
- Bison (Syntax Analyzer)
- GCC (Compiler)
- VS Code
- MSYS2 UCRT64

## Project Structure

- `lexer.l` - Lexical analysis
- `parser.y` - Syntax analysis
- `main.c` - Main program
- `Makefile` - Build automation
- `README.md` - Project documentation

## Current Features

- Keyword recognition
- Identifier recognition
- Integer and floating-point number recognition
- Operator and symbol recognition
- String literal recognition
- Variable declarations
- Variable initialization
- Arithmetic expressions
- Print statements
- If-Else statements
- While loops
- Return statements
- Basic syntax validation
- Invalid syntax detection

## Project Status

Initial development completed. Basic lexical and syntax analysis implemented. Further compiler development is in progress.
